# Proposta arquitetura conceitual para o GRP da PJF

Este repositório contém a proposta de arquitetura para o GRP da PJF, com missão de permitir o desenvolvimento de uma base de código longeva, adaptável e portável.

## Documentação Principal

- **[DESENVOLVIMENTO_INSTRUCOES.md](DESENVOLVIMENTO_INSTRUCOES.md)** - Pré-requisitos, setup de banco, migrations e como rodar frontend/backend/Elsa
- **[AUTENTICACAO_AUTORIZACAO_CONTEXTO.md](AUTENTICACAO_AUTORIZACAO_CONTEXTO.md)** - Fluxo de autenticação, isolamento multilocatário (tenant), compartilhamento de contexto com Elsa, desenvolvimento vs. produção, e suporte a múltiplos frontends (microfrontend/microserviços)
